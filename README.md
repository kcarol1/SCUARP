## Abstarct
In recent years, multi-view subspace clustering methods have demonstrated significant progress in multimodal remote sensing data clustering. However, traditional shallow models are limited in handling complex nonlinear features and fail to fully exploit the deep semantic information in remote sensing data. To address this challenge, we propose deep multi-view subspace clustering via unified anchor and random projection (SCUARP), which couples a parameter-shared nonlinear autoencoder, modality-dependent anchors generated by full-sample random projection, and a single cross-modal anchor-representation matrix within one training objective. This shared representation couples the structures of co-registered HS and LiDAR samples while avoiding costly full graph modeling across all samples. Experimental results on three large-scale multimodal remote sensing datasets demonstrate that our method achieves superior performance compared to existing approaches, with improvements in overall accuracy (OA) by up to 8.87 percentage points on the MUUFL Gulfport dataset and 9.67 percentage points on the Houston dataset, respectively, while offering a favorable practical trade-off between clustering accuracy and computational cost. This study contributes to the field of remote sensing and machine learning by providing an effective and scalable solution for multimodal remote sensing data clustering. 


## Environment

Install a PyTorch build that matches the CUDA version on the machine, then
install the remaining dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

This release was sanity-checked with Python 3.9.21, PyTorch 2.5.1, NumPy 2.0.2,
SciPy 1.13.1, and scikit-learn 1.6.0.

## Running the paper demo

`demo.py` intentionally keeps the original direct-run workflow. There is no new
command-line interface: select one dataset by editing the configuration blocks
near the top of the file, keep only one block active, and run the script from
the repository root:

```bash
python demo.py
```
